# 📦 Hossam ERP - Enterprise Cigarette Cartons Management System

نظام ويب سحابي متكامل لإدارة وتوزيع مخزون سجائر الجملة، حسابات العملاء، المناديب، الخزينة، والمبيعات بالجنيه المصري (EGP).

## 🚀 المميزات الرئيسية
- ⚡ **ربط ومزامنة لحظية مع Firebase Firestore**: تحديث فوري لكافة العمليات (إضافة، تعديل، حذف) عبر الأجهزة.
- 📦 **إدارة المخزون والتوريدات**: متوسط التكلفة الموزون (WAC)، تنبيهات حد الطلب الحرج، وتعديل الرصيد المتاح.
- 🧾 **نقطة البيع (POS)**: إصدار وطباعة فواتير حرارية A4/80mm، خصومات، فواتير نقدية وآجلة.
- 👤 **إدارة حسابات العملاء والديون**: تتبع المديونيات، سندات القبض، ومشاركتها عبر واتساب.
- 🚗 **إدارة المناديب والعهد**: تخصيص خطوط السير والعملاء، متابعة العهد النقدية والبضاعة، وتوريدات الخزينة.
- 🏦 **الخزينة المركزية ورأس المال**: تقارير الأرباح والخسائر، قيود النقدية، وتدقيق المحاسبة اللحظي.
- 🔐 **نظام أمني وصلاحيات دقيقة**: حماية كاملة لحسابات الإدارة والمستخدمين.

## 🛠️ التقنيات المستخدمة
- **Frontend**: HTML5, Vanilla JavaScript (ES6+), Modern Modular CSS.
- **Backend / Cloud**: Google Firebase (Firestore & Authentication).
- **Architecture**: Real-time snapshot listeners with local cached optimistic UI.
